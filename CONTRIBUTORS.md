## Attribution

All commits authored through the DocPro.Cloud team session format carry a
`Co-Authored-By: DocPro.Cloud <team@docpro.cloud>` trailer alongside the
model-specific attribution. This is automated via the `.githooks/prepare-commit-msg`
hook — see [DEPLOY.md](Docs/ToastRevival/DEPLOY.md) or run
`git config core.hooksPath .githooks` after cloning.

## How to contribute

This is a passion project. Pull requests welcome. Issues get looked at when they
get looked at. If you fix something useful, send the PR — see
[README-SELF-HOST.md](README-SELF-HOST.md) for the project's posture.
