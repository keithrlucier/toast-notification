## Verification (Keith's lab, 2026-05-08)

### Get-ScheduledTask output

```
PS C:\WINDOWS\system32> Get-ScheduledTask -TaskPath '\Toast2IT\' -TaskName 'ToastNotificationAgentLogon' |
                          Format-List TaskPath,TaskName,State,Principal,Triggers,Actions

TaskPath  : \Toast2IT\
TaskName  : ToastNotificationAgentLogon
State     : Ready
Principal : MSFT_TaskPrincipal2
Triggers  : {MSFT_TaskLogonTrigger}
Actions   : {MSFT_TaskExecAction}
```

- **State=Ready** — task is registered and armed
- **Principal=MSFT_TaskPrincipal2** — Task Scheduler v2 principal (CIM class wrapper); the underlying GroupId/RunLevel are inside the CIM object. To expand: `(Get-ScheduledTask ...).Principal | Format-List *`
- **Triggers=MSFT_TaskLogonTrigger** — confirms LogonTrigger element from the XML registered correctly
- **Actions=MSFT_TaskExecAction** — confirms the Exec action with Command/Arguments/WorkingDirectory registered correctly
