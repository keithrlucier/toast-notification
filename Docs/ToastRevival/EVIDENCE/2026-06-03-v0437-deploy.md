# v0.4.37 Deploy Verification — 2026-06-03

## What shipped

- `SelfUpdateService.cs` — msiexec runs via standalone SYSTEM scheduled task
  (`\Toast2IT\ToastNotificationApplyUpdate`) instead of as a child process of the
  updater task. Fixes the stuck-upgrade loop observed in field (0.4.35 looping on
  0.4.36, msiexec mid-install holding the Windows Installer mutex). Adds `/l*v`
  install logging to `ProgramData\Toast2IT\Toast Notification\msi-install.log`.
- `TrayIconService.cs` — context menu trimmed: removed "Open Dashboard" and
  "Send Test Notification". Menu is now: View Log / Reconnect Now / Update
  Available (hidden until ready) / Quit.
